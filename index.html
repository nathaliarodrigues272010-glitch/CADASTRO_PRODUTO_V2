Conceito Bootstrap

Bootstrap é uma biblioteca de código aberto que facilita a criação de sites e aplicações modernas e responsivas.

Como ele ajuda no projeto?

  • Criação de botões personalizados.
  • Organização de formulários.
  • Criação de tabelas.
  • Mensagens de alerta.
  • Janelas modais de confirmação.
  • Adaptação da interface para celulares.

Neste projeto, utilizamos CSS e JavaScript próprios para construir componentes semelhantes aos oferecidos pelo Bootstrap.
